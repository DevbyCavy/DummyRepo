# Platinum Interior Design

Website for Platinum Interior Design.

## Requirements

- [XAMPP](https://www.apachefriends.org/) (Apache + PHP + MySQL)

## Local setup

1. Clone the repository into your XAMPP `htdocs` folder:
   ```bash
   cd C:/xampp/htdocs
   git clone https://github.com/DevbyCavy/Platinum-Interior-Design-.git platinumInteriorDesign
   ```
2. Start **Apache** (and **MySQL** if needed) from the XAMPP Control Panel.
3. Open http://localhost/platinumInteriorDesign in your browser.
